Autorize Next-Gen is the next-generation authorization and authentication enforcement detection extension for Burp Suite, completely rewritten for the 2026 application security landscape.

Key Features

  • Zero Jython Dependency: Built natively on Java 21 LTS using the modern PortSwigger Montoya API. Installs with 1 click from the BApp Store.
  • Native Burp Project File Persistence: Test logs, user profiles, rules, and triage results are automatically saved inside your active .burp project database. Results survive Burp restarts, crashes, and project reloads with zero manual exporting.
  • Dynamic Authentication Broker: Automatic token refresh for OAuth 2.0 / 2.1, RFC 9449 (DPoP) ephemeral signature generation, and Anti-CSRF token synchronization.
  • Semantic JSON & GraphQL Diffing: Tree-based comparison that ignores dynamic timestamps, nonces, and session tokens, drastically reducing false ambiguous alerts.
  • Replay Safety Guard: Protects against accidental data destruction by gating state-changing HTTP requests (POST, PUT, DELETE) with safety prompts.
  • Virtual Threads Concurrency: Scales across hundreds of concurrent replayed requests using Java 21 Project Loom.
  • DevSecOps SARIF Export: Export standardized OASIS SARIF vulnerability reports for GitHub Security, GitLab CI, and Jira.
